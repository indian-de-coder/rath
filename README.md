# ROTH 🤖

> **With blessings, we build.**
> **With purpose, we progress.**

RATH is an experimental robotics project built around a easily  available material to build platform. The goal is to design a WiFi telemetry and moror system on wheels with apis controlled by another node running ai model with deep learning capability as a control system the mordan rath.

# CONTEXT

The inspiration comes from the tradition of Rath-Yatra of Lord Jagannath. Every year, a new Rath is built from scratch, piece by piece, and then put to the ultimate test: carrying the traditionally immovable Lord on His journey to His aunt's abode. I see a wonderfully engineered mechanism in this whole tradition. An immovable object is given wheels, a structure, a direction, and a humongous task to do. And somehow, it moves. That is the spirit behind ROTH.

# THE AIM 

1. HARDWARE: A rover with UDP api for telemetry and control, a feed back loop for error correction mechanism. 

2.SOFTWARE: A server running a self learning model controlling the rover via api


# TIMELINE AND FIRST ITARATION GOAL:

1. build a rover with UDP api, telemetry

2. build a python wrapper of the UDP api to connect from a pc

3. use a 4bn parameter model to control it using telemetry as an input
